## 🚀 Key Features

- **Personalized Branding**: Customized for **Ashwani Rathore** with dynamic typing header, custom initials avatar badge, social profile links, and contact options.
- **Hero Section**: Dynamic typing effect (*"Frontend Web Developer", "UI/UX Designer", "CodeAlpha Intern"*), quick resume preview button, and social profile links.
- **About Me**: Interactive bio cards & animated statistics counters (10+ Projects, 100% Responsive, CodeAlpha Tasks).
- **Skills & Proficiency**: Interactive progress bars and skill category cards.
- **Featured Projects**: Filterable project gallery ("All", "CodeAlpha Tasks", "Web Apps") showcasing **Task 2 (Smart Glassmorphic Calculator)** & **Task 3 (Portfolio Site)** with live preview links.
- **Resume Modal & Timeline**: Interactive popup preview modal for reading Ashwani's CV online + direct PDF download option.
- **Contact Form & Info**: Clean, validated message form with live success feedback.
- **Themes & Aesthetics**: Ambient animated blur globes, dark & light theme toggle with `localStorage` memory, responsive navigation drawer, and smooth scrolling.
