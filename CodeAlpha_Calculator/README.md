## 🚀 Key Features

- **Core Arithmetic**: Addition (`+`), Subtraction (`-`), Multiplication (`×`), Division (`÷`).
- **Functionality**: Percentage (`%`), Sign Toggle (`±`), Decimal (`.`), Backspace (`⌫`), All Clear (`AC`).
- **Real-Time Preview**: Dynamic live evaluation as formula expressions are entered.
- **Floating Point Precision**: Clean numerical formatting without JS precision glitches (e.g. `0.1 + 0.2 = 0.3`).
- **Keyboard Support**: Control the calculator directly via keyboard (`0-9`, `+`, `-`, `*`, `/`, `Enter`, `Backspace`, `Esc`, `%`) with visual button press animations.
- **History Panel**: Saves calculations in `localStorage`. Click any entry to re-use previous answers.
- **Glassmorphic UI**: Ambient animated globes, sleek theme toggle (Light / Dark mode).
