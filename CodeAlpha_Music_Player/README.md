## 🚀 Key Features

- **Audio Controls**: Play, Pause, Next Track, Previous Track.
- **Track Information**: Displays song title, artist, genre badge, album cover art, and total duration.
- **Interactive Progress Bar**: Real-time progress fill line with clickable/seekable timeline.
- **Volume & Mute Control**: Interactive volume slider with dynamic volume icon state (high, low, mute).
- **Playback Modes**: Shuffle mode & Repeat mode (Repeat Off, Repeat Song, Repeat All).
- **Interactive Playlist**: Slide-out drawer displaying all tracks with active track highlight and click-to-play.
- **Autoplay Feature**: Automatically advances to the next track when the current song finishes playing.
- **Custom Local Songs Upload**: Users can drag & drop or upload their own MP3 files directly into the player!
- **Visualizer & Animations**: Rotating vinyl record artwork & animated equalizer frequency bars synced to audio playback.
- **Full Keyboard Shortcuts**:
  - `Space`: Play / Pause
  - `◄` / `►`: Seek backward/forward 5 seconds
  - `▲` / `▼`: Volume up/down 10%
  - `N`: Next track
  - `P`: Previous track
  - `M`: Mute / Unmute toggle
